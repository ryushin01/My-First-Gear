# 접근성 점검표 (KWCAG 2.2)

KWCAG 2.2(KS X OT0003) 33개 검사항목을 쇼핑몰과 어드민에 대조한 결과입니다. 항목 번호와 이름은 [비공식 정리본](https://a11ykr.github.io/kwcag22/) 기준이며, 인증이나 인용에는 공식 문서를 확인하세요.

- 자동 검사: Playwright E2E가 프로덕션 빌드의 모든 화면(쇼핑몰 16개, 어드민 6개)을 데스크톱과 모바일에서 axe로 검사하고, 가로 넘침과 24×24px 미만 조작 요소를 찾습니다. Vitest가 공용 컴포넌트를 여러 상태로 렌더링해 axe로 검사합니다.
- 자동 검사를 통과해도 준수는 아니므로 아래 항목은 사람이 직접 확인했습니다. (2026-11-08)

## Next.js 16 Cache Components 주의점

Cache Components를 켜면 Next가 최근 화면 3개를 `display: none`으로 숨긴 채 DOM에 남깁니다. 그래서 다음을 지킵니다.

- 고정 id를 쓰지 않습니다. 클라이언트 컴포넌트는 `useId`, 서버 컴포넌트는 화면마다 다른 접두사(상품 id 등)를 씁니다. 서버의 `useId`는 화면마다 같은 값부터 시작해 겹칠 수 있습니다.
- 본문 바로가기와 오류 요약 링크는 자기 화면 안의 요소로만 초점을 옮깁니다.
- 로그인 상태가 바뀌면 전체 페이지를 다시 불러와 로그인 전 화면이 남지 않게 합니다.
- E2E는 `getByRole` 등 보이는 요소만 고르는 선택자를 씁니다.
